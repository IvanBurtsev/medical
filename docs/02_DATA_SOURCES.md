# Источники данных MedAX Radar

## 1. Модуль 1 — открытые источники (низкий юр. риск)

### 1.1. Росздравнадзор — реестр лицензий
- **URL:** https://roszdravnadzor.gov.ru/opendata
- **Что даёт:** номер лицензии, дата выдачи, лицензиат, ИНН, адрес, виды
  медицинской деятельности.
- **Сигнал:** новая лицензия = новая или расширяющаяся клиника → потенциальная закупка.
- **Режим в демо:** `data/samples/licenses.json` (синтетика).

### 1.2. ФНС / ЕГРЮЛ — регистрация организаций
- **URL:** https://egrul.nalog.ru/
- **Что даёт:** дата регистрации, название, ИНН/ОГРН, ОКВЭД, адрес.
- **Фильтр:** ОКВЭД `86.21`, `86.22`, `86.23` (медицина), `47.73` (аптеки).
- **Отсечение:** ОКВЭД `46.46` (торговля мед. изделиями) — это конкуренты, не лиды.
- **Режим в демо:** `data/samples/companies.json`.

### 1.3. zakupki.gov.ru — госзакупки 44-ФЗ / 223-ФЗ
- **URL:** https://zakupki.gov.ru/
- **Что даёт:** реестровый номер, заказчик, ИНН, регион, НМЦК, даты, ссылку.
- **Фильтр ОКПД2:** `26.60.*`, `32.50.*`, `28.13.14`, `31.09.11`, `14.12.30`.
- **Сигнал:** прямой спрос на оборудование; возможность участия MedAX.
- **Режим в демо:** `data/samples/tenders.json`.

## 2. Модуль 2 — сайты конкурентов (средний юр. риск)

- **Что даёт:** цены, акции, бренды, регионы, промо.
- **Требования:** `robots.txt`, rate limiting, Circuit Breaker, только публичные страницы.
- **Ограничение:** не обходить авторизацию/капчу; иначе — риск ст. 272 УК РФ.
- **Режим в демо:** `data/samples/competitors.json`, **выключен** в конфиге.
  Включается флагом `--competitors` (для демонстрации) или после юрзаключения.

## 3. Приоритетные регионы

Заданы в `config/sources.json → regions_priority` с весами 0.3–1.0.
База MedAX — Ставрополь, поэтому максимальный вес у Ставропольского края,
далее — ЮФО/СКФО.

## 4. Качество данных

| Аспект | Мера |
|---|---|
| Дедупликация | по ИНН, иначе по «название + регион» |
| Полнота | доля заполненных полей (`normalize.completeness`) |
| Свежесть | затухание по дате лицензии/публикации тендера |
| Обогащение | слияние полей из нескольких источников |

## 5. Синтетические данные

Все файлы в `data/samples/` — **вымышленные** и предназначены только для демонстрации.
ИНН, названия и цены не относятся к реальным организациям.
Для продакшена переключите адаптер в `fetch_live()`.
