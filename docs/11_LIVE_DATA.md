# Живые данные: модуль 1 и сравнение цен

## 1. Модуль 1 — реальные закупки (zakupki.gov.ru)

Реализован live-сбор через **официальный RSS поиска** закупок.

- URL: `zakupki.gov.ru/epz/order/extendedsearch/rss.html` + параметры поиска.
- Запросы (поисковые фразы) — в `config/zakupki.json`.
- TLS проверяется с **российским доверенным корневым сертификатом**
  (`certs/russian_trusted_root_ca.pem`), проверка не отключается.
- Соблюдаются robots.txt и rate limiting.
- Парсер достаёт: реестровый номер, предмет закупки, заказчика, НМЦК,
  дату размещения, ссылку.

```bash
python run.py run --competitors --live --export
```

> Примечание: с зарубежного IP zakupki отвечает медленно (десятки секунд на
> запрос). С российского хостинга — быстро.

### Ограничение
RSS не содержит регион заказчика. Регион можно достать отдельным запросом
карточки закупки (задача на развитие); сейчас поле пустое.

## 3. Сравнение цен MedAX ↔ конкуренты

### Как работает
1. Собирается собственный каталог MedAX с `medaxgroup.ru`
   (`medax_radar/medax_catalog.py`): имя/цена/категория/ссылка.
2. Берутся предложения конкурентов из базы (модуль 2).
3. Товары сопоставляются по категории и схожести названий (Jaccard по токенам).
4. Формируется позиционирование по категориям и пары «наш ↔ конкурент».

### Команды
```bash
python run.py compare --live            # собрать каталог MedAX и сравнить
python run.py compare --threshold 0.3   # строже сопоставление
python run.py compare --json            # машинный вывод
```

### Результат
`runtime/reports/price_comparison.md` и `.json`.

Пример реального совпадения:

| Категория | MedAX | ₽ | Конкурент | ₽ |
|---|---|---:|---|---:|
| uzi | УЗИ аппарат Mindray Imagyn I9 | 3 350 000 | MEDLIGA | 3 350 000 |

### Настройка
- Категории для сбора — `config/medax_site.json`.
- Порог схожести — параметр `--threshold` (по умолчанию 0.2).
- Офлайн-снимок каталога — `data/samples/medax_products.json`.

### Ограничения
Сопоставление названий приблизительное; для точности в будущем — словарь
синонимов и нормализация моделей/брендов. Сейчас лучше всего работает на
однотипных категориях (УЗИ, томографы, компрессоры).
