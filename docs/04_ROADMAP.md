# Дорожная карта MedAX Radar

## Принцип

Сначала ценность на открытых данных, потом усложнение.
Каждый этап заканчивается измеримым результатом, а не «слоем».

## Этап 0 — Подготовка (неделя 1)

- Назначить ответственного за эксплуатацию.
- Утвердить бюджет (сервер РФ + LLM-подписка).
- Подтвердить целевой регион пилота (ЮФО/СКФО).
- Согласовать доступ к Bitrix для выгрузки лидов.

**Результат:** owner, бюджет, регион зафиксированы.

## Этап 1 — Модуль 1 на открытых данных (недели 2–4)

- Подключить 3 источника: Росздравнадзор, ФНС, zakupki.gov.ru.
- Реализовать нормализацию, дедупликацию, матчинг, скоринг.
- Выгрузка лидов в CSV/JSON/Markdown + дашборд.

**Результат:** ≥ 50 лидов/мес с объяснением. (**В демо уже реализовано.**)

## Этап 2 — Пилот с отделом продаж (недели 5–8)

- Интеграция лидов в CRM (Bitrix).
- Сбор обратной связи: какие лиды реально полезны.
- Калибровка весов скоринга по фактической конверсии.

**Результат:** подтверждённая полезность ≥ 30% лидов.
**Решение:** продолжать / менять источники / остановить.

## Этап 3 — Модуль 2: конкуренция (недели 9–12, при юрзаключении)

- Мониторинг цен и акций дистрибьюторов-конкурентов.
- Матчинг «наш SKU ↔ конкурент», отчёт по позиционированию.
- Соблюдение robots.txt, rate limiting, Circuit Breaker.

**Результат:** отчёт «где мы дороже/дешевле».

## Этап 4 — Интеллект и прогноз (по спросу)

Рассматривается только при наличии платящего спроса:
- Извлечение из PDF-прайсов и сложных страниц (LLM).
- Сигналы expansion (вакансии, новые лицензии, филиалы).
- Прогноз закупок.

## Этап 5 — Платформенные улучшения (только по необходимости)

- PostgreSQL вместо SQLite.
- Очередь для параллельного сбора.
- Расширенная observability.

> GraphRAG, multi-agent, Confidential Computing, Event Backbone **не являются
> целями** дорожной карты. Они вводятся только при доказанной необходимости.

## Матрица «этап → метрика»

| Этап | Ключевая метрика |
|---|---|
| 1 | ≥ 50 лидов/мес, точность матчинга ≥ 80% |
| 2 | ≥ 30% полезных лидов, первые сделки |
| 3 | Покрытие цен конкурентов ≥ 70% ключевых SKU |
| 4 | Точность прогноза expansion ≥ 60% |
