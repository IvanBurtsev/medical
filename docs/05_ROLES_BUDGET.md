# Роли, бюджет и эксплуатация

## 1. Роли

| Роль | Ответственность | Кто |
|---|---|---|
| Владелец продукта (owner) | Приоритеты, бюджет, приёмка | **Назначен** |
| Ответственный за эксплуатацию | Запуск, мониторинг, data quality | Требуется назначить |
| Разработчик | Пайплайн, адаптеры, дашборд | Исполнитель (AI-ассистент / разработчик) |
| Владелец процесса продаж | Обратная связь по лидам, CRM | Руководитель отдела продаж |
| Юрист | Заключение по модулю 2, 152-ФЗ | Внешний/штатный юрист |

**Принцип:** owner не обязан писать код, но обязан принимать решения и
обеспечивать обратную связь. Без ответственного за эксплуатацию инструмент деградирует.

## 2. Бюджет (пилот, ориентировочно)

| Статья | Вариант | Ориентир/мес |
|---|---|---|
| Сервер (РФ) | 4 vCPU / 8–16 GB RAM | 1 500 – 4 000 ₽ |
| LLM (для сложного извлечения) | API с data retention off | 2 000 – 15 000 ₽ |
| Хранилище/бэкапы | PostgreSQL, S3-совместимое (РФ) | 500 – 2 000 ₽ |
| Юрзаключение (разово) | Модуль 2 | 30 000 – 150 000 ₽ |
| Разработка | По этапам | По договорённости |

**Минимальный пилот:** только сервер + (опционально) LLM. Демо работает на
стандартной библиотеке Python — без платных компонентов.

## 3. Что НЕ покупать на старте

- OneTrust / SAS AI Navigator / Collibra.
- Confidential Computing (Intel TDX / AMD SEV-SNP).
- Redpanda / Kafka, Neo4j, GPU-кластер для локальных LLM.
- Дорогие enterprise-EDA-платформы.

Эти расходы оправданы только после подтверждения продукт-маркет фита.

## 4. Эксплуатация

| Процесс | Периодичность | Ответственный |
|---|---|---|
| Прогон пайплайна | 1–7 раз/нед | Эксплуатация |
| Проверка нового источника | при добавлении | Разработчик |
| Калибровка скоринга | ежемесячно | Owner + продажи |
| Обновление правовых политик | ежеквартально | Юрист |
| Резервное копирование БД | ежедневно | Эксплуатация |

## 5. Риски и митигация

| Риск | Влияние | Митигация |
|---|---|---|
| Нет ответственного за эксплуатацию | Инструмент не обновляется | Назначить в этапе 0 |
| Устаревание источника | Падение качества | Мониторинг, адаптеры |
| Юридические претензии (модуль 2) | Высокое | Юрзаключение, robots.txt |
| Переусложнение | Срыв сроков | Принцип минимализма |
| Низкая полезность лидов | Потеря бюджета | Ранний пилот с продажами |
