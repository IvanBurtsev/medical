# Ответственное использование

## 1. Принципы

1. **Не навредить.** Сбор не должен влиять на доступность чужих сервисов.
2. **Только публичное.** Собираем лишь то, что опубликовано намеренно.
3. **Минимум.** Не собираем больше, чем нужно для задачи.
4. **Прозрачность.** Бот идентифицируем, контакт рабочий.
5. **Уважение.** Просьба о прекращении сбора исполняется немедленно.
6. **Контроль.** Любой сбор можно остановить одной командой.

## 2. Красные линии (запрещено всегда)

- Обход авторизации, капчи, paywall.
- DDoS-подобная нагрузка.
- Сбор персональных данных пациентов и сотрудников.
- Получение коммерческой тайны.
- Маскировка под иных лиц.

## 3. Управление списком доменов

- Ведётся allowlist доменов для модуля 2.
- Новый домен добавляется вручную с проверкой `robots.txt`.
- Исключение домена — по требованию правообладателя, без обсуждения.

## 4. Журналирование

Фиксируются: домен, время, объём запросов, отказы robots.txt, ошибки.
Журналы доступны юристу и ответственному за эксплуатацию.

## 5. Порядок действий при инциденте

1. Немедленно остановить сбор (флаг/остановка сервиса).
2. Зафиксировать инцидент и объём данных.
3. Уведомить владельца продукта и юриста.
4. Выполнить remediation и повторную оценку.

## 6. Ответственность

Ответственный за эксплуатацию обеспечивает соблюдение политики.
Владелец продукта утверждает изменения и несёт ответственность перед
заказчиком.
