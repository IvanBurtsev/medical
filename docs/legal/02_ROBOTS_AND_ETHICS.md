# Политика сбора: robots.txt, нагрузка и этика

## 1. robots.txt

- Проверка обязательна для каждого запроса (по умолчанию в `HttpClient`).
- При `Disallow` запрос **не выполняется**, фиксируется отказ.
- `Crawl-delay` соблюдается, даже если он больше нашего rate limit.
- При недоступности `robots.txt` действует правило «разрешено» (стандартное
  поведение), но включается консервативный rate limit.

Реализация: `medax_radar/net/robots.py` (`RobotsCache`), тесты — `tests/test_net.py`.

## 2. Нагрузка

| Механизм | Значение по умолчанию |
|---|---|
| Token bucket на хост | 1 req/sec, burst 1 |
| Backoff при ошибке | экспоненциальный, база 0.5 c |
| Повторные попытки | 3 |
| Уважение `Retry-After` / 429 / 5xx | да |

Запрещено: параллельные всплески, игнорирование 503, обход «троттлинга»
через прокси без согласования с юристом.

## 3. Идентификация

User-Agent имеет вид:

```
MedAXRadarBot/4.0 (+https://medaxgroup.ru/; compliance@medaxgroup.ru)
```

Это позволяет правообладателю связаться с нами и потребовать прекращения
сбора. Контактный адрес должен быть рабочим.

## 4. Этические принципы

1. Не навредить работе сайта.
2. Собирать только то, что опубликовано намеренно.
3. Не маскироваться под обычного пользователя.
4. Уважать просьбы о прекращении сбора.
5. Хранить минимум необходимого.

## 5. Эскалация

| Событие | Действие |
|---|---|
| Правообладатель просит прекратить | Немедленно исключить домен из allowlist |
| Код 403/429 систематически | Приостановить домен, снизить частоту |
| Юридический запрос | Передать юристу, заморозить сбор |
| Подозрение на ПДн в выдаче | Остановить парсер, уведомить ответственного |
