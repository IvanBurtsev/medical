# Юридический пакет MedAX Radar

Пакет документов для получения юридического заключения и для
compliance-by-design при разработке модуля 2 (конкурентная разведка).

> Материалы носят организационно-технический характер и не являются
> юридическим заключением.

| [03_DATA_PROCESSING.md](03_DATA_PROCESSING.md) | Описание обработки данных и PII |
| [04_QUESTIONS_TO_COUNSEL.md](04_QUESTIONS_TO_COUNSEL.md) | Список вопросов для письменного заключения |

| [06_LEGAL_REQUEST_TEMPLATE.md](06_LEGAL_REQUEST_TEMPLATE.md) | Готовый шаблон запроса в юридическую фирму |
