# MedAX Radar

**B2B-платформа рыночной разведки и коммерческих сигналов для [MedAX Group](https://medaxgroup.ru/).**

Демо-версия 4.0. Показывает полный конвейер: сбор открытых данных →
нормализация → дедупликация → матчинг с каталогом MedAX → объяснимый скоринг
лидов → дашборд и отчёты. Работает на стандартной библиотеке Python 3.11+,
без внешних зависимостей.

---

## Зачем это нужно

MedAX Group — поставщик и интегратор медицинского оборудования (Ставрополь):
каталог стоматологического и диагностического оборудования, услуги «клиника
под ключ», проектирование, лицензирование, сервис, обучение.

**Клиники — это покупатели MedAX, а не конкуренты.** Конкуренты — другие
дистрибьюторы оборудования и интеграторы. Продукт построен вокруг этого факта:

| Модуль | Что делает | Источники | Юр. риск |
|---|---|---|---|
| **1. Радар спроса** | Находит новые клиники, которым скоро понадобится оборудование | Росздравнадзор, ФНС, zakupki.gov.ru | Низкий |
| **2. Радар конкуренции** | Следит за ценами и акциями дистрибьюторов-конкурентов | Сайты конкурентов | Средний → после юрзаключения |

## Быстрый старт

Требуется только Python 3.11+ (внешние библиотеки не нужны).

```bash
# 1. Полный цикл: сбор + скоринг + вывод лидов + экспорт отчётов
python run.py run --competitors --export --verbose

# 2. Живые данные: реальные закупки + каталог конкурентов + сравнение цен
python run.py run --competitors --live --export   # live-сбор
python run.py compare --live                      # цены MedAX ↔ конкуренты

# 3. Только лиды
python run.py leads --limit 15

# 4. Веб-дашборд
python run.py dashboard --port 8080
#   → http://127.0.0.1:8080

# 5. Статус источников и проверка конфигурации
python run.py sources
python run.py health
python run.py validate

# 6. Тесты (без внешних зависимостей)
python -m unittest discover -s tests -v
```

Запуск в Docker:

```bash
docker compose up --build -d      # → http://localhost:8080
```

## Как работает скоринг

Оценка 0–100, полностью объяснимая. Веса заданы в `config/sources.json`:

| Сигнал | Вес | Логика |
|---|---:|---|
| Свежесть лицензии | 30 | Затухание, half-life 120 дней |
| Тендерная активность региона | 25 | Свежие закупки, half-life 45 дней |
| Приоритет региона | 20 | Близость к базе MedAX |
| Совпадение с каталогом | 15 | Число релевантных категорий |
| Полнота данных | 10 | Контакты и реквизиты |

Уровни: **HOT ≥ 75**, **WARM ≥ 50**, **COLD < 50**.
Изменить поведение можно без правки кода — только через конфиг.

## Правовой контур

- Основа модуля 1 — **открытые государственные данные**.
- Персональные данные пациентов **не собираются и не хранятся**.
- Модуль 2 (парсинг конкурентов) запускается **только после юридического
  заключения**, с соблюдением `robots.txt` и rate limiting.
- EU AI Act для рынка РФ не обязателен; продукт не относится к high-risk.

Подробнее — `docs/03_LEGAL_COMPLIANCE.md`.

> Все данные в `data/samples/` **синтетические и вымышленные**, предназначены
> только для демонстрации.

и `MEDAX_DATABASE_URL=postgresql://...`. Подробнее — `docs/07_DEPLOYMENT.md`.

## Модуль 2 — радар конкуренции

Включён по решению владельца. Собираются только **публичные** страницы каталогов
конкурентов с соблюдением `robots.txt`, rate limiting и allowlist доменов
(`config/competitors.json`). Парсинг: JSON-LD / microdata / regex-фолбэк.

```bash
python run.py run --competitors --live --export          # живой сбор
python run.py scrape https://competitor.ru/catalog/ --json  # одна страница
```

Юридические материалы — `docs/legal/`, описание модуля — `docs/10_MODULE2.md`.

## Принципы проекта

1. **Открытые реестры — сначала, парсинг — потом.**
2. **Минимализм.** Никаких Redpanda/Neo4j/GraphRAG/Confidential Computing
   на этапе пилота. Только то, что приносит ценность сейчас.
3. **Compliance by default.**
4. **Объяснимость.** У каждого лида есть причины.
5. **Развитие по спросу.** Усложнение — только после подтверждённой пользы.

## Описание продукта

MedAX Radar — это инструмент, который превращает открытые данные о рынке
медицинских услуг в конкретные коммерческие действия. Вместо ручного поиска
новых клиник и тендеров отдел продаж получает ранжированный, объяснимый список
лидов, сопоставленный с реальным каталогом и услугами компании.

Архитектурная ставка сделана сознательно: сначала — ценность на данных с
низким юридическим риском (государственные реестры), затем — расширение на
конкурентную разведку, и только при доказанном спросе — на более тяжёлые
технологии (графы знаний, агентные системы, прогнозная аналитика).

Демо-версия полностью воспроизводит ключевой конвейер и работает без
внешних зависимостей, что позволяет запустить пилот немедленно и наращивать
сложность по мере подтверждения пользы.
